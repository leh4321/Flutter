Touch Maze 개인정보 처리방침

'Touch Maze'(이하 '앱')는 사용자의 개인정보를 소중히 다루며, 관련 법령을 준수하여 사용자의 권익을 보호하기 위해 다음과 같은 지침을 수립합니다.

1. 개인정보 처리 목적 및 수집 항목

본 앱은 원활한 게임 서비스 제공을 위해 최소한의 정보를 활용하며, 구체적인 목적과 항목은 다음과 같습니다.

  • 구글 플레이 게임 서비스(GPGS) 연동: 사용자의 게임 진행 데이터 저장 및 리더보드(순위표) 기능을 제공하기 위해 구글 계정 정보를 활용합니다.
  • 수집 항목: 구글 플레이 게임즈 프로필 이름(닉네임), 고유 사용자 ID, 게임 점수(포인트)

2. 데이터의 저장 및 제3자 제공

본 앱은 사용자의 보안을 최우선으로 하며 데이터 처리에 있어 다음 원칙을 준수합니다.

  • 서버 저장 방식: 본 앱은 자체 서버를 운영하지 않으며, 모든 게임 데이터와 점수는 Google Play 게임 서비스(Google Cloud) 서버에 안전하게 저장됩니다.
  • 데이터 공유 금지: 수집된 점수와 프로필 정보는 게임 내 리더보드 출력을 위해서만 사용되며, 어떠한 경우에도 마케팅 목적으로 제3자에게 제공하거나 판매하지 않습니다.

3. 개인정보의 보유 및 파기

데이터의 보유 기간 및 파기 절차는 다음과 같습니다.

  • 사용자가 구글 플레이 게임즈 설정에서 '게임 데이터 삭제'를 요청할 경우 즉시 파기됩니다.
  • 앱 삭제 시 기기 내 임시 저장된 설정값은 즉시 제거되나, 리더보드에 등록된 점수는 구글 계정 서비스를 통해 관리되므로 사용자가 직접 구글 계정 설정에서 관리할 수 있습니다.

4. 이용자의 권리

이용자는 언제든지 게임 내 설정을 통해 로그아웃하거나, 구글 계정 설정을 통해 본 앱에 제공한 데이터 접근 권한을 철회할 수 있습니다.

5. 개인정보 및 데이터 삭제 요청 (User Data Deletion)

본 앱은 사용자의 데이터를 소중히 관리하며, 사용자는 언제든지 본인의 개인정보 및 게임 데이터 삭제를 요청할 권리가 있습니다.

  • 삭제 요청 방법: 아래 개발자 이메일로 삭제 요청이라는 제목과 함께 본인의 게임 닉네임 또는 고유 ID를 보내주시기 바랍니다.
  • 처리 절차: 요청 접수 후 7일 이내에 해당 사용자와 관련된 모든 데이터를 Google Play 게임 서비스 서버에서 영구적으로 삭제 처리합니다.
  • 직접 삭제 방법: 사용자는 본인의 기기 내 [Google Play 게임즈] 앱 설정 메뉴에서 '게임 데이터 삭제'를 통해 직접 즉시 삭제하실 수도 있습니다.
